# 天界ちほー9（heaven9 区域）
::: info 区域简介
Alos 与 Selepris 射出的白箭袭击了天界，将铁壁般的防御穿出一个洞。
:::
::: tip 一些小信息
一道闪光袭击了守护天界的“祈祷之壁”。那就是开始的信号。
:::

> アルオスとセレプリスのはなった白き矢は天界を襲い、鉄壁の防御に穴を穿った

::: tip 一些小信息
天界を護る『祈りの壁』を襲った一筋の閃光。それが始まりの合図だった。 
:::
</details>
